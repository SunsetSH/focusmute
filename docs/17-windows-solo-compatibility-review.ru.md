# Краткое ревью: FocusMute, Windows и Scarlett Solo 4th Gen

Дата: 21 сентября 2026. Ревью относится к FocusMute 0.11.0 и Scarlett Solo 4th Gen, подключённой по USB.

**Вывод:** исходная реализация использовала для Solo предположения, унаследованные от Scarlett 2i2. Для Solo требуется отдельный профиль адресов и индексов LED; это реализовано в текущей версии. Конкретные журналы, серийные номера, токены сессий и снимки локального устройства намеренно не публикуются.

## Основания и пределы проверки

Изучены библиотека, Windows/WASAPI backend, tray/CLI, настройки, reconnect, blink, тесты и исследования протокола. В локальной изолированной проверке дополнительно читались параметры подключённого Solo через официальный Windows-драйвер PAL/SwRoot. Записи, переключающие mute, Air или Direct, при этой части исследования не выполнялись.

Ревью проверяет совместимость одной конфигурации Windows с официальными компонентами Focusrite. Оно не является заявлением о поддержке всех версий драйвера, прошивки и Focusrite Control.

## Основные выводы

| Приоритет | Вывод | Практическое следствие |
|---|---|---|
| P0 | У Solo другие поля single-LED команды | Цвет записывается в поле 80, индекс — в 84; bulk-массив начинается в 88. |
| P0 | Физическая карта Solo не совпадает с прогнозом 2i2 | Номера каналов подтверждены как LED 4 и LED 12. |
| P1 | Кольца уровня принадлежат прошивке | Она сразу возвращает отображение фактического входного сигнала; постоянный цвет halo нельзя считать надёжным mute-индикатором. |
| P1 | Состояние Windows mute и аппаратный meter различаются | Полоса уровня показывает сигнал на входе, но не подтверждает слышимость собеседником. |
| P1 | Событие Direct сообщает об изменении состояния | Одно нажатие для mute и двойное для Direct возможно только как эксперимент с компенсацией штатного действия. |

Полная проверенная карта LED и безопасная стратегия восстановления приведены в [документе 21](21-solo-led-map-and-restoration.ru.md).

## Windows и USB

Официальный драйвер предоставляет необходимый транспорт: инициализацию, транзакции и асинхронные уведомления. Переустановка драйвера или замена его на WinUSB не исправляет ошибки выбора LED-полей. Важные требования для приложения — привязка к правильному capture endpoint, обработка смены устройства/сна и корректная остановка фонового I/O.

Mute реализуется через Windows endpoint volume. Поэтому он не должен выдаваться за универсальный аппаратный mute для ASIO, Direct Monitor и всех exclusive-mode сценариев. См. документацию Microsoft: [IAudioEndpointVolume](https://learn.microsoft.com/en-us/windows/win32/api/endpointvolume/nn-endpointvolume-iaudioendpointvolume).

## Air и Direct

Air, Inst, 48V, USB, Output и Direct не должны изменяться LED-индикатором mute. На Solo FocusMute адресует только проверенные номера каналов и не использует `DATA_NOTIFY(5)`: массовая команда может погасить независимые LED, а их исходный цвет невозможно безопасно восстановить.

Для Direct доступна отключённая по умолчанию экспериментальная функция. Одиночное короткое нажатие переключает Windows mute, двойное оставляет штатное переключение Direct. Удержание кнопки зарезервировано прошивкой для Combine Inputs и не переопределяется. См. [аппаратные функции Solo](https://userguides.focusrite.com/hc/en-gb/articles/17505454690706-Scarlett-Solo-Hardware-Features) и [Combine Inputs](https://support.focusrite.com/hc/en-gb/articles/14653126009490-Scarlett-Solo-4th-Gen-one-or-two-input-app-compatibility).

## Ограничения

Автоматический mute от положения ручки Gain не реализован: в доступной цифровой модели наблюдается уровень входного сигнала, а не положение аналоговой ручки. Для такого режима требуется отдельный подтверждённый источник цифрового значения gain.
