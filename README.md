# FocusMute

FocusMute переключает mute системного микрофона горячей клавишей и показывает это состояние на Focusrite Scarlett 4th Gen. Эта версия серьёзно адаптирована для **Scarlett Solo 4th Gen по USB**, но сохраняет исходную логику 2i2: для каждой модели выбирается свой профиль светодиодов.

Исходный код: <https://github.com/SunsetSH/focusmute>

## Что умеет программа

- глобальная горячая клавиша mute и push-to-talk;
- горячая клавиша продолжает переключать mute, пока открыто окно настроек;
- русская и английская локализация, захват сочетания клавиш прямо в поле настройки;
- выбор входа Solo: инструментальный 1, микрофонный 2 или оба;
- цветовая индикация и мигание номеров каналов при mute;
- опциональная обработка кнопки Direct на Solo: одно нажатие переключает mute, двойное сохраняет штатное переключение Direct;
- индикация уровня выбранных входов и предупреждение «мигание при разговоре»;
- звук, уведомления, автозапуск, webhooks и синхронизация с расширением браузера.

## Solo: проверенная карта LED

Работа с Solo построена на эксперименте с конкретной картой, а не на предположениях. Основная документация: [карта LED и безопасное восстановление](docs/21-solo-led-map-and-restoration.ru.md). Исходные наблюдения: [`docs/20-ledtest.md`](docs/20-ledtest.md).

| LED | Назначение | Действие FocusMute при mute |
|---:|---|---|
| 4 | номер канала 1 | выбранный цвет для входа 1 |
| 12 | номер канала 2 | выбранный цвет для входа 2 |
| 6–11, 13–19 | кольца уровней входов | не изменяются |
| 0, 2, 3, 24–27, 31 | Air, Inst, 48V, Output, USB, Direct | не изменяются |

При выходе из mute FocusMute возвращает только затронутые номера в белый цвет. Он не посылает bulk-команды и не меняет режим LED: такие команды на Solo могут погасить независимые индикаторы, а прошивка всё равно сразу возвращает кольца уровней к фактическому звуку.

## Использование

Запустите `focusmute.exe` на Windows. Приложение появится в системном трее. В **Настройках → Основные**:

1. выберите «Вход 1 — инструмент», «Вход 2 — микрофон» или оба;
2. задайте цвет mute и режим «Только номера» либо «Мигание при mute»;
3. щёлкните «Записать» рядом с горячей клавишей и нажмите сочетание;
4. нажмите «Применить», затем «Сохранить».

«Мигание при разговоре» — отдельное предупреждение: когда Windows mute включён, а уровень выбранного входа выше порога, номер канала кратко мигает. Полоса ниже показывает входной сигнал самой карты и не является состоянием Windows mute.

Для Solo экспериментальная опция Direct доступна в **Настройки → Основные**. Короткое одинарное нажатие переключает mute; быстрое двойное нажатие остаётся переключением Direct. Проверьте эту опцию на своей карте перед повседневным использованием.

Конфигурация сохраняется в `%APPDATA%\Focusmute\config.toml` на Windows и `~/.config/focusmute/config.toml` на Linux. Минимальный пример:

```toml
[indicator]
mute_color = "#FF0000"
mute_inputs = "all"       # all | 1 | 2 | 1,2
mode = "numbers_blink"    # auto | numbers | numbers_blink

[keyboard]
hotkey = "Ctrl+Shift+M"

[system]
language = "ru"           # en | ru

[hardware_button]
direct_button_enabled = false
direct_double_click_ms = 350
```

## Сборка

Нужен стабильный Rust с Cargo. Для воспроизводимой сборки из уже скачанного кэша:

```powershell
cargo build --locked --release --workspace
cargo test --locked --workspace
```

Исполняемые файлы появятся в `target\release\`:

- `focusmute.exe` — приложение в трее;
- `focusmute-cli.exe` — командная строка.

Для Windows MSI используется WiX: `cargo wix --package focusmute`. Для Linux инструкции и зависимости находятся в [dist/linux/README-linux.md](dist/linux/README-linux.md). Полное руководство по сборке и проверке Solo: [docs/19-build-and-solo-guide.ru.md](docs/19-build-and-solo-guide.ru.md).
